# Arielzinha

Arielzinha é um bot de música para Discord, desenvolvido a partir do [MuseHeart-MusicBot](https://github.com/zRitsu/MuseHeart-MusicBot). O projeto mantém a base e os créditos da implementação original, com desenvolvimento próprio no repositório [DEVenur/Arielzinha](https://github.com/DEVenur/Arielzinha).

O objetivo é oferecer reprodução e controle de música diretamente em servidores Discord, com comandos e recursos integrados à experiência do Discord.

## Recursos

- **Controles de música:** comandos para reproduzir, pausar, retomar, pular e controlar a reprodução.
- **Player interativo:** interface de controle com suporte a skins personalizáveis.
- **Comandos flexíveis:** suporte a comandos de barra, prefixo (padrão `?`) e menções ao bot.
- **Discord Rich Presence (RPC):** integração com a presença do Discord.
- **Last.fm:** integração para registrar (scrobble) as músicas escutadas.
- **Fontes de áudio:** suporte a diferentes serviços e fontes compatíveis com a configuração do Lavalink.

> A disponibilidade de cada fonte de áudio depende dos plugins, serviços externos e da configuração da instância Lavalink utilizada.
